# 图片泛化脚本 · 使用说明

这是「数据飞轮」第 7 步的独立脚本：以你**已标注**的数据为种子，  
在**未被抽样**的数据中找出视觉相似的图片，输出它们的 URL 列表。

> 它和评测工具是**分开的两步**（两段式）。评测工具只负责导出数据，本脚本负责算相似度。  
> 好处是：你的电脑上不用装几个 GB 的 AI 环境，装在哪台机器上跑都行。

---

## 一、开始前：你需要准备什么

| 项目        | 要求                                  |
| --------- | ----------------------------------- |
| 操作系统      | Windows / Mac / Linux 都行            |
| Python 版本 | **3.10 或 3.11**（不要用太新的版本，AI 库可能不兼容） |
| 硬盘空间      | 至少 5GB（放 AI 模型 + 图片缓存）              |
| 网络        | 需要联网下载图片和模型                         |

**有显卡（NVIDIA）会快很多，但没有也能跑**（用 CPU）。

### 第 1 步：确认 Python 已安装

打开命令行（Windows 按 `Win + R`，输入 `cmd` 回车），输入：

  去 <https://www.python.org/downloads/> 下载 **3.11** 版本，  
  安装时**务必勾选 `Add Python to PATH`**（很重要，否则命令行找不到）。

### 第 2 步：进入脚本目录

假设你把整个项目放在 `C:\Users\EDY\WorkBuddy\2026-08-10-00-36-53`，

## 三、使用步骤

### 第 1 步：从评测工具导出"泛化数据包"

1. 打开评测工具，完成评测
2. 点顶部 **「导出数据」** 按钮
3. 在弹出的面板里：
   - **勾选**要泛化的标签
   - 选择标注结果：**正确 / 错误 / 全部**
     - 选「错误」= 难例挖掘（找模型可能也会判错的相似图）
     - 选「正确」= 扩充同类样本
   - 点 **「导出泛化数据包（CSV）」**
4. 保存得到 `泛化数据包.csv`

### 第 2 步：运行脚本

把 `泛化数据包.csv` 放到 `泛化脚本` 文件夹里，然后执行：

```
python generalize.py --input 泛化数据包.csv --output 相似数据结果.csv
```

跑完会生成 `相似数据结果.csv`。

### 第 3 步：查看结果

输出的 CSV 包含这些列：

| 列名                       | 说明                |
| ------------------------ | ----------------- |
| 规则标识                     | 规则号               |
| 规则名称                     | 标签名               |
| 种子数据行ID / 种子URL / 种子标注结果 | 用来做比对的**已标注**原始数据 |
| 相似数据行ID / 相似URL          | 找出来的**相似**数据      |
| 相似度                      | 0~1，越接近 1 越像      |

## 四、常用参数

| 参数             | 默认            | 说明                       |
| -------------- | ------------- | ------------------------ |
| `--threshold`  | 0.85          | 相似度阈值。**低于此值的结果不输出**     |
| `--topk`       | 20            | 每张种子图最多返回多少条             |
| `--workers`    | 16            | 并发下载线程数。网速好可以调大（如 32）    |
| `--batch-size` | 32            | 特征提取批大小。**内存不足就调小**（如 8） |
| `--cache`      | ./image_cache | 图片缓存目录                   |
| `--device`     | auto          | `auto` / `cpu` / `cuda`  |

**例子**：降低阈值、多找一些结果：

```
python generalize.py --input 泛化数据包.csv --output 结果.csv --threshold 0.75 --topk 50
```

## 五、耗时参考

| 数据规模  | 下载（瓶颈）   | 特征提取（CPU 8核） | 特征提取（GPU） |
| ----- | -------- | ------------ | --------- |
| 3 千张  | 1~3 分钟   | 约 1 分钟       | 几秒        |
| 3 万张  | 10~30 分钟 | 约 3 分钟       | 约 30 秒    |
| 30 万张 | 2~6 小时   | 约 30 分钟      | 约 5 分钟    |

> ⚠️ **时间主要花在下载图片上**，不是计算。  
> 网速慢的话，先把 `--workers` 调大试试。

## 六、常见问题

**Q：提示"没有找到相似度 ≥ 0.85 的数据"**  
A：阈值太高了。加 `--threshold 0.75` 重跑。

**Q：下载失败很多**  
A：图片源站可能限流。降低并发（`--workers 8`）并增加重试（`--retries 5`）。

**Q：内存不足 / 程序被杀**  
A：调小批大小：`--batch-size 8`。

**Q：想换模型**  
A：加 `--model facebook/dinov2-large`（更准但更慢）。  
其他可选：`facebook/dinov2-small`（更快）。

**Q：重跑会不会重新下载图片？**  
A：不会。图片缓存在 `image_cache` 目录，第二次跑会直接复用。

**Q：结果能直接进训练集吗？**  
A：**建议先抽查确认**。这些是"推断标签"（继承了种子的标注结果），  
相似度越低越不可靠。建议：相似度 >0.95 可较放心采用，0.85~0.95 抽查后再用。
